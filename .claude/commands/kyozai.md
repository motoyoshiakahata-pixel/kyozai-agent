description: "公共の教材（共通テスト形式の問題）を、単元番号やキーワードだけで手早く作成開始する"
---

`kyozai` スキルを使って、公共の教材作成を始めてください。

## 依頼内容

```
$ARGUMENTS
```

## 進め方

1. `.claude/skills/kyozai/units.md` の単元一覧を読み、依頼内容に含まれる番号（①〜⑤などの丸数字や「2」のような数字）またはキーワードから、対象の単元名・ページ範囲・教科書PDFを特定してください。
   - 番号だけの依頼（例:「②」「② 3問」）は、その番号の単元名・ページ範囲をそのまま使う。
   - 単元名やキーワードが書かれていれば、それを優先する。
   - ④のように単元名が未設定の番号が指定されたら、作成プランを提示する前に、対象単元を教えてもらうよう確認する。
   - 問題数の指定がなければ3問とする。
   - 単元一覧にない範囲が指定された場合は、教科書PDFのファイル名（章・テーマとページ範囲）から該当箇所を判断する。
2. 特定できたら、`kyozai` スキルの指示（参照フォルダ・出典ルール・出題パターン・答案様式・承認ゲート）に従って作成を進めてください。ここから先は通常の `/kyozai` 依頼とまったく同じ流れです（プラン提示 → 承認 → 問題案提示 → 承認 → 保存）。
