`kyozai` スキルを使って、公共の教材作成を始めてください。

## 依頼内容

```
$ARGUMENTS
```

## 進め方

- 依頼内容に単元名・対象ページ範囲・問題数が含まれていれば、それに従って `kyozai` スキルの手順（参照フォルダ・出典ルール・出題パターン・答案様式・承認ゲート）で作成を進めてください。
- 単元名やページ範囲が書かれていない場合は、作成プランを立てる前に「どの単元でしょうか（教科書のページ範囲が分かれば教えてください）」と確認してください。単元番号や過去の資料から単元名を推測しないでください。
- 問題数の指定がなければ3問とします。
